# Sudarshan App

This repository was empty. I added a minimal static site skeleton so you can connect this repo to Netlify for deployment.

How to deploy to Netlify

1. Go to https://app.netlify.com/sites and click "Add new site"  "Import from Git".
2. Connect your GitHub account and choose the repository `sheevu/Sudarshan-app`.
3. For build settings, since this is a static site, you can leave the build command empty and set the publish directory to `.` (repository root), or change as needed.
4. Deploy. Subsequent pushes to `main` will trigger new deploys.

If you want a different framework (React/Vue/Next.js), tell me and I can scaffold and add a build pipeline.
